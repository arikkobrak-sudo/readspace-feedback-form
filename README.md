# ReadSpace — форма зворотного зв'язку

Адаптивна форма «Напишіть нам» для платформи ReadSpace з клієнтською валідацією на JavaScript і регулярних виразах. Лабораторна робота №9 з курсу «Технології веб-розробки та дизайну».

## Можливості

- Поля: ім'я, email, телефон (`+380XXXXXXXXX`), повідомлення, згода з політикою конфіденційності.
- Mobile-first верстка на Tailwind CSS: одна колонка на телефоні, дві — від `md`.
- Валідація на `input`, `blur` і `submit`; червона рамка й текст помилки під полем, зелена рамка для правильного поля.
- Модальне вікно після успішної перевірки (закриття кнопкою, Esc, кліком по фону; фокус утримується всередині).
- Доступність: `label`/`for`, `aria-describedby`, `aria-invalid`, керування з клавіатури.

> Серверної частини немає: після перевірки дані нікуди не надсилаються, модальне вікно лише демонструє успішну клієнтську валідацію.

## Структура

```
index.html               — розмітка сторінки й форми
assets/css/input.css     — вхідний файл Tailwind
assets/css/styles.css    — зібраний CSS (підключений на сторінці)
assets/js/validation.js  — валідація, стани полів, модальне вікно
assets/images/           — логотип ReadSpace
assets/fonts/            — шрифт Inter
tailwind.config.js       — дизайн-токени ReadSpace
```

## Запуск

Відкрити `index.html` у браузері. Перезбирання стилів після зміни класів:

```
npm install
npm run build
```
